# Security policy

## Report a vulnerability

Report security problems privately. Do not open a public issue.

Use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/csimonson62/selection-tint/security/advisories/new).

Include:

- What the problem is and what it lets someone do.
- Steps to reproduce it.
- The version of selection-tint (`.claude-plugin/plugin.json`) and of the Claude desktop app.

You get a reply within 7 days.

## Supported versions

Only the latest version on `main` gets fixes.
